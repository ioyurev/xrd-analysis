# Атлас неорганических структурных типов по Ульриху Мюллеру

Настоящее руководство предназначено для идентификации кристаллических структур, подбора изоструктурных прототипов и генерации гипотез о кристаллических фазах на основе химического состава и стехиометрии.

## 1. Плотнейшие упаковки и заселение междоузлий

Большинство неорганических бинарных и псевдобинарных кристаллов описываются плотнейшей упаковкой анионов (или крупных катионов) с частичным или полным заселением октаэдрических ($O$) и тетраэдрических ($T$) пустот.

## 2. Перовскиты и толеранс-фактор Гольдшмидта

Семейство перовскитов описывается общей формулой $ABX_3$ (катион $A$ в 12-координации, катион $B$ в октаэдре $[BX_6]$).

### 2.1. Формулы факторов устойчивости

1. **Фактор толерантности Гольдшмидта ($t$):**
   $$t = \frac{r_A + r_X}{\sqrt{2}(r_B + r_X)}$$
   где $r_A, r_B, r_X$ — эффективные ионные радиусы Шеннона с учетом координационных чисел: $\text{CN}(A) = 12$, $\text{CN}(B) = 6$, $\text{CN}(X) = 6$ (или 2).

2. **Октаэдрический фактор ($\mu$):**
   $$\mu = \frac{r_B}{r_X}$$
   Геометрический порог стабильности октаэдра: $\mu \ge \sqrt{2}-1 \approx 0.414$.

### 2.2. Структурные режимы и типы искажений

| Диапазон $t$ | Описание структуры | Пространственная группа | Пример / Прототип |
| :--- | :--- | :--- | :--- |
| **$t > 1.04$** | Гексагональные политипы с реберным/гранецентрированным сочленением октаэдров | $P6_3/mmc$ (2H, 4H, 6H, 9R) | $\text{BaNiO}_3$, $\text{BaTiO}_3$ (гекс.) |
| **$0.95 < t \le 1.04$** | Идеальный кубический перовскит, отсутствие наклонов октаэдров | $Pm\bar{3}m$ (221) | $\text{SrTiO}_3$, $\text{KTaO}_3$, $\text{CsPbI}_3$ (выс. T) |
| **$0.90 < t \le 0.95$** | Ромбоэдрическое искажение (синфазные/противофазные наклоны) | $R\bar{3}c$ (167) | $\text{LaAlO}_3$, $\text{BiFeO}_3$ |
| **$0.80 \le t \le 0.90$** | Ромбический перовскит ($\text{GdFeO}_3$-тип, система наклонов Глейзера $a^-b^+a^-$) | $Pnma$ (62) | $\text{CaTiO}_3$, $\text{GdFeO}_3$, $\text{SmScO}_3$, $\text{YAlO}_3$ |
| **$t < 0.80$** | Разрушение каркаса перовскита: структура ильменита или $\text{LiNbO}_3$ | $R\bar{3}$ (148), $R3c$ (161) | $\text{FeTiO}_3$, $\text{MgTiO}_3$, $\text{LiNbO}_3$ |

## 3. Шпинели $AB_2X_4$ и инверсия

Структура шпинели основана на ГЦК-упаковке анионов $X$ ($Z=8$ формульных единиц в элементарной ячейке, $Fd\bar{3}m$). Из 64 тетраэдрических позиций занято 8 (позиция $8a$), из 32 октаэдрических — 16 (позиция $16d$).

### 3.1. Параметр инверсии ($\lambda$)
Общая формула распределения катионов:
$$(A_{1-2\lambda} B_{2\lambda})_{\text{tet}} [A_{2\lambda} B_{2-2\lambda}]_{\text{oct}} X_4, \quad \lambda \in [0, 0.5]$$
* **Нормальная шпинель ($\lambda = 0$):** $(A)_{\text{tet}}[B_2]_{\text{oct}}O_4$ (например, $\text{MgAl}_2\text{O}_4$, $\text{Co}_3\text{O}_4$, $\text{FeCr}_2\text{O}_4$).
* **Обращенная шпинель ($\lambda = 0.5$):** $(B)_{\text{tet}}[AB]_{\text{oct}}O_4$ (например, $\text{Fe}_3\text{O}_4 = (\text{Fe}^{3+})_{\text{tet}}[\text{Fe}^{2+}\text{Fe}^{3+}]_{\text{oct}}\text{O}_4$, $\text{NiFe}_2\text{O}_4$).
* **Смешанная (промежуточная) шпинель:** $0 < \lambda < 0.5$, зависит от температуры отжига и скорости охлаждения (закалки).

### 3.2. Энергия стабилизации кристаллическим полем (LFSE / OSSE)
Предпочтение катионов переходных $3d$-металлов к октаэдрической координации определяется октаэдрической энергией стабилизации:
$$\text{OSSE} = \text{LFSE}_{\text{oct}} - \text{LFSE}_{\text{tet}}$$
* Катионы с высоким $\text{OSSE}$ ($\text{Cr}^{3+} (d^3)$, $\text{Ni}^{2+} (d^8)$) строго занимают октаэдры $\to$ стабилизируют нормальную или обращенную шпинель соответственно.
* Катионы с нулевым $\text{OSSE}$ ($\text{Mn}^{2+} (d^5)$, $\text{Fe}^{3+} (d^5)$, $\text{Zn}^{2+} (d^{10})$) легко занимают тетраэдры.

## 4. Фазы Цинтля и полианионные каркасы

Фазы Цинтля образуются между высокоэлектроположительными элементами (щелочные, щелочноземельные металлы, РЗЭ) и умеренно электроотрицательными p-элементами групп 13–15.

### 4.1. Обобщенное правило $8-N$
Электроположительный металл $A$ полностью отдает валентные электроны полианионной подрешетке $X$. Анионы $X$ образуют ковалентные связи между собой для замыкания октаэдра валентных электронов:
$$e_{\text{transferred}} + e_{\text{valence}}(X) + b_{XX} = 8$$
где $b_{XX}$ — число ковалентных 2c-2e связей $X-X$ на один атом аниона.

### 4.2. Валентная электронная концентрация $\text{VEC}(X)$
$$\text{VEC}(X) = \frac{\sum e_{\text{valence}}}{N_X}$$
* $\text{VEC} = 8$: Изолированные анионы $X^{n-}$ без ковалентных связей $X-X$ (например, $\text{Mg}_2\text{Si}$, $\text{Ca}_3\text{Bi}_2$).
* $\text{VEC} = 7$: Гантели $[X_2]^{2-}$ с одинарной связью (аналоги галогенов, e.g. $\text{CaC}_2$, $\text{BaGe}_2$).
* $\text{VEC} = 6$: 1D цепи или кольца $[X]_n$ с 2 связями (аналоги халькогенов, e.g. $\text{CaSi}$, $\text{BaSn}$).
* $\text{VEC} = 5$: 2D гофрированные слои с 3 связями (аналоги мышьяка/фосфора, e.g. $\text{CaSi}_2$).
* $\text{VEC} = 4$: 3D полианионный каркас алмазоподобного типа (e.g. $\text{NaTl}$).
